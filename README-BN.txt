EDITZ MOTION LAB BY SAWN — WEBSITE FILES
========================================

এই ZIP-এর মধ্যে আছে:
- index.html       মূল ওয়েবসাইট
- privacy.html     Privacy Policy
- terms.html       Terms of Use
- help.html        Help / FAQ

কীভাবে চালাবেন:
1. ZIP extract/unzip করুন।
2. সব HTML ফাইল একই ফোল্ডারে রাখুন।
3. index.html খুললে ওয়েবসাইট দেখা যাবে।
4. Hosting-এ আপলোড করার সময় ZIP-এর ভেতরের ফাইলগুলো একসঙ্গে আপলোড করবেন; ZIP-এর বাইরের parent folder নয়।

গুরুত্বপূর্ণ:
- এটি একটি static promotional website।
- এখানে এখনো login, account database, payment, admin panel বা APK download কাজ করে না।
- Android app development-এ আছে; প্রস্তুত ও পরীক্ষা না হওয়া পর্যন্ত fake download button রাখা হয়নি।
- Privacy/Terms পেজগুলো starter text; বাস্তবে user data/payment যোগ করার আগে আইন ও প্রকৃত service অনুযায়ী update করতে হবে।
- YouTube ও Telegram link যুক্ত করা আছে।

মোবাইল থেকে hosting:
Cloudflare Pages-এর Direct Upload-এ ZIP file upload করা যায়। Dashboard-এ Workers & Pages > Create application > Pages > Direct Upload / Upload assets নির্বাচন করে ZIP দিন, তারপর Deploy করুন।
Official guide: https://developers.cloudflare.com/pages/get-started/direct-upload/

নিজের .com domain যুক্ত করতে hosting live হওয়ার পর Cloudflare Pages project-এর Custom domains অংশে domain যোগ করতে হবে।
